# U.S. Retail Sales Trends

A data analysis & visualization project exploring 34+ years (1992–2026) of
U.S. Advance Retail Sales data, published by the U.S. Census Bureau and
retrieved via FRED (Federal Reserve Economic Data). Includes data
processing, a from-scratch seasonal decomposition + trend forecasting
model, chart generation, and a final PDF report.

📄 **[Read the full report](report/US_Retail_Sales_Report.pdf)**

## Key findings

- Retail sales grew **~380%** from January 1992 (\$159B/mo) to July 2026 (\$764B/mo).
- Two recessions stand out clearly in the data: the **2008 Financial Crisis**
  (sales fell ~12% peak-to-trough) and **COVID-19** (a ~22% two-month
  collapse in Feb–Apr 2020, followed by the fastest recovery in the dataset).
- Growth has **accelerated since 2021**: the trailing 5-year growth rate
  (~\$29B/year) is roughly double the 34-year long-run average (~\$15B/year).
- The published series is already seasonally adjusted by the Census Bureau —
  running an independent decomposition on top of it recovers a (correctly)
  almost-flat seasonal index, which is used here as a sanity check rather
  than a discovery.

## Data source

**U.S. Census Bureau, Advance Retail Sales: Retail Trade and Food Services
[RSAFS]**, retrieved from FRED, Federal Reserve Bank of St. Louis:
https://fred.stlouisfed.org/series/RSAFS

- Units: Millions of dollars, seasonally adjusted
- Frequency: Monthly
- Range used: January 1992 – July 2026 (415 observations)

## Methodology

1. **Feature engineering** (`data/process_data.py`) — month-over-month and
   year-over-year % change, 12-month rolling mean/std, and flags for three
   NBER-dated recessions that fall in the sample window (2001, 2008–09, 2020).
2. **Seasonal decomposition** (`model/trend_model.py`) — a classical
   multiplicative decomposition implemented from scratch with pandas/numpy:
   a 2×12 centered moving average for the trend-cycle, a normalized
   seasonal index per calendar month, and a remainder term.
3. **Forecasting** — rather than fitting one straight line across all 34
   years (which understates the recent acceleration in growth), a local
   linear trend is fit on just the most recent 60 months and projected
   forward 12 months, then re-seasonalized. This is a simple, fully
   transparent trend extrapolation — not a production forecasting model.
   See the report's Limitations section for caveats.

No black-box time-series libraries (e.g. `statsmodels`, `prophet`) are used
— everything is implemented directly with `pandas`, `numpy`, and
`scikit-learn`'s `LinearRegression`, so every step is inspectable.

## Reproducing this project

```bash
pip install -r requirements.txt

python data/process_data.py       # -> data/retail_sales_processed.csv
python model/trend_model.py       # -> data/retail_sales_forecast.csv, model/model_summary.txt
python analysis.py                # -> charts/*.png
python report/generate_report.py  # -> report/US_Retail_Sales_Report.pdf
```
