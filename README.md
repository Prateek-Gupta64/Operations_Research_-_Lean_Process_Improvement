# Operations_Research_-_Lean_Process_Improvement
Data analysis project exploring 34+ years (1992–2026) of U.S. retail sales from the Census Bureau/FRED. Includes cleaned datasets, a from-scratch seasonal decomposition + trend forecasting model, 8 visualizations covering growth, recessions (2008, COVID-19), and a 12-month forecast, plus a full PDF report — all reproducible with included scripts.
